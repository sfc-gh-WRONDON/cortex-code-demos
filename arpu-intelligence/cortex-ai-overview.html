Live Demos

Two use cases built on UnitedMasters data already in Snowflake

1. Simplified Amplitude

Leadership IC Engineers

The Problem: Engineers now own features end-to-end and need to understand which product features users interact with. Amplitude requires significant ramp-up time, especially for non-PMs.

The Solution: A simpler, conversational interface over Amplitude event data already ingested into Snowflake — powered by Cortex AI. Anyone can ask product usage questions in natural language without learning Amplitude's UI.

2. ARPU Intelligence Dashboard

Ops Team Artists

Internal View: Streamlit dashboard with ARPU trends by tier, churn risk scoring (ML Classification), revenue anomaly detection, and AI-generated recommendations per artist.

External View: Cortex Agent that lets artists ask questions about their own streaming data, royalties, and growth opportunities — governed by RBAC so each artist sees only their data.

What ties them together: Both demos use data already in Snowflake, require zero data movement, and layer Cortex AI (Search, Analyst, ML, AI_COMPLETE) on top of governed tables — showing a path from raw event data to self-service intelligence in days, not quarters.
